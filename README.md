# Telegram-бот салонов красоты «Эпатаж»

Бот отвечает клиентам на вопросы об услугах, ценах, адресах и акциях сети салонов «Эпатаж» (studia-epatage.ru) и собирает заявки на запись: имя, телефон, услугу, салон, время. Заявки пересылаются в Telegram-чат администраторов. Работает на Vercel и Claude API (модель Haiku).

- **Как запустить** (без технических знаний): [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)
- **Что знает бот** (редактируемый текст): [knowledge/epatage.md](knowledge/epatage.md)
- **Проект бота** (цели, метрики, риски): [docs/chatbot-design.md](docs/chatbot-design.md)

## Устройство
| Файл | Назначение |
|---|---|
| `api/telegram.js` | Принимает сообщения от Telegram (webhook), проверяет секрет |
| `api/setup.js` | Одноразовое подключение webhook: откройте `/api/setup` |
| `lib/bot.js` | Ответы по кэшируемой базе знаний; анкета заявки (данные хранятся в сообщении бота, клиент отвечает на него); отправка заявки администраторам |
| `knowledge/epatage.md` | База знаний, собранная с сайта |

Настройки окружения: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`, `ADMIN_CHAT_ID` (номер чата для заявок, узнать командой `/id`; можно несколько через запятую), необязательно `CLAUDE_MODEL` (по умолчанию `claude-haiku-5-5`).
